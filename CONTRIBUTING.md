# Изменения

Перед изменением поведения согласуйте структуру и интерфейс в issue.
Для pull request опишите проблему, изменение и выполненные проверки.
Сохраняйте совместимость с Python 3.10 и новее и выполняйте тесты из README с доступом к X11.
Автоматические тесты не должны требовать настоящего ключа, захватывать звук
пользователя или выполнять платные запросы. Сквозные звуковые тесты проводятся
отдельно с разрешения пользователя общего аудиовыхода.

Не добавляйте секреты, журналы сеансов, локальные настройки или `.venv`.
