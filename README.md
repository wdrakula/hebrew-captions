# Hebrew Captions — иврит → русский

Локальное приложение для Linux: слушает воспроизводимый системный звук,
распознаёт речь на иврите через OpenAI и показывает перевод на русский
в отдельном окне с прокручиваемой историей.

Подходит для YouTube в браузере, лекций и конференций. Звук захватывается напрямую
через PulseAudio monitor во время воспроизведения. Видео не скачивается,
аудиофайлы для последующей обработки не создаются.

## Возможности

- Два переключаемых режима: обычная транскрипция и Live.
- Следование за устройством вывода по умолчанию, включая Bluetooth-наушники.
- Локальное определение речи Silero VAD с одним вычислительным потоком.
- Русские субтитры с историей: свежая реплика выделена, предыдущие сохраняются.
- Автопрокрутка останавливается при чтении истории; кнопка возвращает к текущему.
- Размер шрифта, прозрачность, необязательный показ иврита и пропуск кликов через окно.
- Понятное сообщение при недостаточном балансе API.
- Журнал задержек и использования API без текста речи, аудио и ключей.

В пользовательском тесте обычный режим оказался предпочтительнее по качеству
и задержке. Это наблюдение для конкретного компьютера и речи, а не гарантия
преимущества модели или универсальное сравнение стоимости.

## Требования

Проверено на Linux Mint 22.3, X11, Python 3.12. Нужны работающий PulseAudio
(или совместимый сервер с `pactl` и `parec`), интернет и собственный OpenAI API-ключ.
Для Wayland пропуск кликов через окно не реализован.

## Установка

Скачайте проект через GitHub **Code → Download ZIP** и распакуйте либо клонируйте
репозиторий. В папке проекта выполните:

```sh
sudo apt install python3.12-venv python3-tk pulseaudio-utils git
./install.sh
```

Установщик создаёт локальное окружение `.venv`, устанавливает Python-зависимости
и проверяет контрольную сумму включённой модели VAD. Он не меняет аудиоустройства
и не выполняет платные запросы.

После добавления ключа запустите:

```sh
./run.sh
```

Необязательно: добавьте приложение в меню системы:

```sh
python3.12 install-menu.py
```

Ярлык привязан к текущей папке проекта. После переноса папки установите его заново.

## Получение и размещение ключа

1. Войдите в [OpenAI API Platform](https://platform.openai.com/).
2. Откройте [API keys](https://platform.openai.com/api-keys) и создайте секретный
   API-ключ для своего проекта. Сохраните его при создании.
3. Проверьте [API billing](https://platform.openai.com/settings/organization/billing/overview):
   для платных запросов нужен доступный баланс/оплата API. Подписка ChatGPT
   оплачивается отдельно и не заменяет оплату API. Проверьте настройку автопополнения.
4. Создайте **APIkey.txt в папке приложения, рядом с run.sh**. Вставьте только
   сам ключ, одной строкой, без кавычек и дополнительных подписей.
5. Ограничьте доступ к файлу:

   ```sh
   chmod 600 APIkey.txt
   ```

Один ключ используется для распознавания и перевода; отдельного речевого ключа
не требуется. Доступ к используемым моделям зависит от проекта OpenAI.

Альтернативы: переменная `OPENAI_API_KEY` или файл `.env` с записью
`OPENAI_API_KEY=ваш_ключ` (образец — `.env.example`). Приоритет: переменная окружения,
`.env`, локальный `APIkey.txt`. Для исходной локальной установки сохранён совместимый
поиск `APIkey.txt` тремя уровнями выше папки приложения.

Не публикуйте ключ в репозитории, скриншотах или обращениях об ошибках.
`.gitignore` исключает ключи, `.env`, журналы, настройки и `.venv`.
При исчерпании квоты приложение показывает «Оплатите ключ API!!!! 😉»
и позволяет повторить запуск после оплаты. Другие ошибки отображаются отдельно.

Инструкция основана на [официальном руководстве OpenAI](https://developers.openai.com/api/docs/quickstart).

## Как пользоваться

1. Откройте ролик или конференцию и выберите нужный выход звука обычным способом.
2. Запустите приложение. До нажатия **«Начать»** захвата и платных запросов нет.
3. Выберите **«Обычный — по фрагментам»** или **«Live — быстрый»**, нажмите **«Начать»**.
4. Разместите окно субтитров там, где удобно читать. Свежий текст выделен белым.
5. Для чтения истории прокрутите вверх. Для продолжения автопрокрутки нажмите
   **«К текущему ↓»**.
6. **«Пауза»** завершает текущую фразу и перевод. Закрытие управления отменяет
   работу; незавершённый результат может быть потерян.

Режим можно менять во время работы: приложение завершает текущую фразу и перевод,
затем открывает новую STT-сессию. История сохраняется в течение запуска приложения.
Закрытие окна субтитров скрывает его; кнопка управления возвращает окно.

По умолчанию захватывается **весь звук текущего вывода**, включая уведомления
и другие приложения. Отдельное окно браузера не выбирается. В «Дополнительно»
можно указать конкретное устройство вместо следования выходу по умолчанию.
Пауза нужна перед изменением этих настроек.

## Обработка и стоимость

| Режим | Распознавание | Границы аудио | Перевод |
| --- | --- | --- | --- |
| Обычный | `gpt-transcribe` | 1,2 с нового звука; 0,4 с перекрытия на принудительных границах | После финального STT |
| Live | `gpt-live-transcribe`, `delay=low` | До паузы; защитная граница 6 с | Растущий текст обновляет одну запись истории |

Оба режима используют WebSocket-сессию транскрипции с языком `he`.
Перевод выполняет `gpt-4o-mini` с контекстом последних шести завершённых фрагментов.
У Live промежуточные изменения объединяются; новый промежуточный перевод
запускается не раньше чем через 1,5 с после предыдущего. Совпадающий финальный
текст использует готовый перевод. Промежуточные переводы могут увеличивать расход.

Silero VAD работает локально: порог 0,35, предварительный звук и хвост паузы
по 300 мс. Он уменьшает отправку тишины, но не гарантирует отсечение музыки/пения.
Обычный режим консервативно удаляет точные повторы минимум двух слов в перекрытии;
на границах возможны повторы и обрезанные слова.

Аудио речи отправляется OpenAI для STT, распознанный текст — для перевода.
Это локальная программа с облачными моделями, поэтому без интернета распознавание
и перевод не работают. Тарифы и доступность моделей могут изменяться;
см. [OpenAI pricing](https://developers.openai.com/api/docs/pricing).

## Проверки и ограничения

Автоматические проверки покрывают разбиение и перекрытие, порядок STT-ответов,
остановку и переключение, ошибки квоты, промежуточный перевод, историю,
прокрутку и X11-пропуск кликов. Запуск без платных запросов:

```sh
.venv/bin/python -m unittest discover -s tests -q
```

Для тестов окон нужен доступ к X11. Короткие сквозные тесты использовали настоящий
звук YouTube через monitor. В одном тесте обычного режима медианная задержка
русского текста была около 3,85 с от начала фрагмента (пять результатов).
Это малый замер, не обещание скорости. Silero с ресемплингом занимал примерно
3–5% одного логического ядра на i5-8350U; это не общая нагрузка браузера и приложения.

Качество зависит от речи, шума, громкости и облачных моделей. Имена и короткие
фрагменты могут распознаваться неверно. Полноценная проверка длительных конференций
и сквозного переключения моделей ещё не проведена. [Архитектура](docs/ARCHITECTURE.md)
и [решение типичных проблем](docs/TROUBLESHOOTING.md).
